# Instagram Operator Packet
Inkbound Night Desk — AI Influencer Agency
Version 2026-09-11.2

The agency prepares work. A person posts.
This file is the Instagram desk. Load it before you write a caption or create an account.

## The standard
These accounts are a door to the press. They are not a second imprint, not a dating profile, and not a mystery to be solved.
A post is finished when four things are true:
1. The face matches the lock.
2. The sentence could only belong to that persona.
3. The pointer goes to the house, or there is no pointer.
4. A stranger can tell, without hunting, that the speaker is an AI persona for Inkbound Night Desk.
If any one fails, the post is not late. It is unsent.
Kids-channel work does not enter this file.

## 0. Order of operations
1. Pick the influencer (`vera-ink`, `night-archivist`, or `chief.py new`).
2. Generate three stills. Save under `influencers/<slug>/refs/` with the names in section 5.
3. Sign Gate 1 into `audit/`.
4. Build the Instagram account from section 2. Flip the profile label before post one.
5. Run Days 1-30 from section 7.
6. Sign Gate 2 on the week before anything goes up.
7. Post from the pre-flight card. File Gate 3. Score the link, not the likes.
Until Gate 3 is signed: packet built, not posted.
