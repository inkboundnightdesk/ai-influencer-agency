# Influencers

One folder per persona. Spawn with:

```bash
python3 scripts/chief.py new --niche dark-romantasy --name "Mara Vesper"
```

Do not hand-make a folder unless you are copying `_template/` on purpose.
`chief.py list` only sees folders that contain `persona.yaml`.

Voice calibration: load `voice-gold.md` after `voice.md`. Starters already have gold.
A week that cannot sit next to the gold set does not go to Gate 2.
